# Data

## Folders

| Path | Contents | In git |
| --- | --- | --- |
| `raw/online_retail_sample.csv` | Synthetic sample, ~46,000 lines, same schema as UCI Online Retail | Yes |
| `raw/online_retail_full.csv` | Official dataset (541,909 lines), created by `basketlens download` | No (download it) |
| `sample/online_retail_real_sample.csv` | 40 authentic lines from the UCI data, used in tests | Yes |
| `processed/` | Pipeline outputs used by Power BI and the NoSQL loaders | Yes (regenerated by `basketlens run`) |

## The official dataset

Chen, D. (2015). *Online Retail* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5BW33 — licensed CC BY 4.0.

Transactions of a UK-based online retailer of all-occasion gifts, many of whose customers are wholesalers, between 1 December 2010 and 9 December 2011.

```bash
pip install ucimlrepo
basketlens download                                   # -> data/raw/online_retail_full.csv
basketlens run --input data/raw/online_retail_full.csv
```

The Excel file from the UCI website also works: `basketlens run --input "Online Retail.xlsx"` (needs `openpyxl`).

| `country_sales.csv` | Country | Power BI |
| `product_sales.csv` | Product: revenue, units, ABC class, return rate | Power BI |
| `basket_rules.csv` | Product pair rule: support, confidence, lift | Power BI |
| `cohort_retention.csv`, `cohort_revenue.csv` | Cohort × month | Power BI |
| `weekday_hour_orders.csv` | Weekday × hour | Power BI |
| `anomalies.csv`, `forecast.csv` | Day | Power BI |
| `cancellations.csv` | Cancellation line | Power BI |
| `data_quality.csv` | Cleaning step | Power BI, audit |

The dashboard reads one compact file, `dashboard/data/basketlens_data.js`, written by the same run.
